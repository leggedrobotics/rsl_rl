# Instructions for Agents

- Read `CONTRIBUTING.md` before making changes.
- Do not add or change code comments unless explicitly requested.
- When opening a PR from a fork, enable "Allow edits from maintainers" and verify that it is enabled.
- Keep regression tests minimal and proportionate to the risk of recurrence; avoid elaborate setup or broad test
  matrices for narrowly scoped fixes.
- Add tests to the existing test file corresponding to the modified module; do not create separate files for individual
  bug fixes.
